Georgian law, inside your AI assistant

Fuzzzy Law is a free connector. It lets ChatGPT, Claude, Gemini and other assistants read Georgian law at the source: the exact current text from matsne.gov.ge with the official link, earlier wordings back to 2015, and published court decisions.

No account with us, nothing to install on the web, and it is free.

Connector address
https://law-api.fuzzzycore.com/mcp

Add this address once in your assistant's settings. How to do it is below.

Three steps

  1. Add the address to your assistant

    Steps for each assistant are below.

  2. Send it the ready-made message

    It tells the assistant how to work with the law. The text is here.

  3. Ask your question as usual

    The assistant quotes the article word for word and links to matsne.gov.ge. It can still make mistakes, so check the link.

Connect your assistant

Any app that can add a remote MCP server works with this address. No sign-in and no key are needed. Button names are given exactly as they appear in each app.

Claudeclaude.ai, desktop app, phone, Claude Code {{icons:chevron}}

Plans: Free (one custom connector only), Pro, Max, Team and Enterprise. On Team and Enterprise an organisation owner adds it, and members then turn it on themselves.

  1. Open claude.ai or the Claude desktop app and go to Customize › Connectors.
  2. Click “+ Add”, then “Add custom connector”.
  3. Enter the name Georgian law, paste the connector address as the server URL and click “Continue”. Then click “Continue” once more.
  4. Under Authentication choose “No sign in” and click “Add”.
  5. In a chat, click “+” at the lower left, choose Connectors and turn Georgian law on.

On a phone: add it on the web first. It then appears in the Claude app on iPhone and Android.

From Anthropic's documentation, checked {{vendor_checked}}. support.claude.com

Claude Code

One command in the terminal:

claude mcp add --transport http georgian-law https://law-api.fuzzzycore.com/mcp

Check it with claude mcp list. If you signed in to Claude Code with a claude.ai account, a connector added on claude.ai appears there by itself.

ChatGPTchatgpt.com, web only {{icons:chevron}}

Plans: Business, Enterprise and Edu (an admin or owner adds it). Pro can connect it with read-only permissions. OpenAI's documentation does not mention Free, Go or Plus, so it may not work there. It cannot be added from the phone app.

  1. Open chatgpt.com/plugins.
  2. Select the plus button, then “Add custom MCP server”.
  3. Enter the name Georgian law. Under Connection, paste the connector address into “Server URL”.
  4. For authentication, choose “No authentication”.
  5. Read the warning, select “I understand and want to continue”, then “Create as a plugin”.
  6. Install the new plugin. In a chat, type @ and pick Georgian law.

From OpenAI's documentation, checked {{vendor_checked}}. developers.openai.com, help.openai.com

Geminithe Gemini app cannot connect yet {{icons:chevron}}

The ordinary Gemini app has no setting for adding a connector like this today. Google documents only a test mode for developers (Gemini Apps Developer Mode), and adding an address without sign-in is not confirmed there. So we cannot recommend the Gemini app for now.

Gemini CLI (in the terminal) does work:

gemini mcp add --transport http -s user georgian-law https://law-api.fuzzzycore.com/mcp

-s user adds it for all your projects. Check it with /mcp in a session.

From Google's documentation, checked {{vendor_checked}}. developers.google.com, Gemini CLI

Other appsVS Code, Cursor, Codex and similar {{icons:chevron}}

VS Code (GitHub Copilot): in the Command Palette choose “MCP: Add Server”, then HTTP, and paste the connector address. On Copilot Business and Enterprise an admin must turn MCP on first.

Cursor: add this to ~/.cursor/mcp.json:

{ "mcpServers": { "georgian-law": { "url": "https://law-api.fuzzzycore.com/mcp" } } }

Codex CLI:

codex mcp add georgian-law --url https://law-api.fuzzzycore.com/mcp

Mistral Le Chat, Perplexity (Pro and above), Zed, JetBrains AI Assistant and LM Studio also take this address; the steps are in the full guide. The ordinary Microsoft Copilot cannot add a custom connector.

How it stays current

  • Every night at 01:17 UTC (05:17 in Tbilisi), every law's page on matsne.gov.ge is checked again. A law that has changed is read again.
  • A new text replaces the old one only when every article is present and every line matches matsne word for word. Each night, 50 stored articles chosen at random are also compared on their own.
  • If a check fails, the last confirmed text stays. After three days without a successful check, every answer carries a warning.
  • Earlier wordings are kept and never change, so an article can be read as it stood on a given day.
  • Court decisions are not yet updated automatically: new ones are added in batches. Last update: {{cov:courts_updated_text}}.
  • Amendments that are adopted but not yet in a consolidated text on matsne are not held.
  • Everything is downloaded the way the sites allow: following their robots.txt rules, one request at a time, at least 10 seconds apart.

Before you rely on it

  • We are not lawyers. We did our best to get this right.
  • This is legal information, not legal advice.
  • Only the {{cov:laws}} laws listed above are held. Other laws, government and ministry acts, municipal acts, decisions of city (district) courts and courts of appeal, international treaties and judgments of the European Court of Human Rights are not.
  • The Supreme Court's collections are a selection the court makes, not every decision. If no decision is found, that does not mean none exists.
  • The assistant can still make mistakes. Check the article at its official link and, when it matters, ask a lawyer.

Privacy

Your questions are not stored. To protect against abuse, the server keeps a network log for seven days: IP address, time, requested path and response status.

This page sets no cookies and loads no trackers. Your theme choice and the latest numbers are kept only in your browser. Your conversation happens in your assistant, under its company's rules.
