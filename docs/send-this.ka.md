# გაუგზავნე შენს ასისტენტს

როცა Fuzzzy Law-ის კონექტორს ჩართავ ([დაკავშირების ინსტრუქციები](connect/README.md)), ახალ საუბარში ჯერ ეს ტექსტი ჩასვი და გაგზავნე. ამის შემდეგ ასისტენტი საქართველოს კანონმდებლობის კითხვებზე კონექტორის წყაროებით გიპასუხებს.

```text
საქართველოს კანონმდებლობის შესახებ ყოველ კითხვაზე გამოიყენე Fuzzzy Law-ის კონექტორი და მიჰყევი მის ინსტრუქციებს; თუ ის არ გაქვს, მითხარი და მეხსიერებიდან ნუ მიპასუხებ.
უპასუხე მხოლოდ იმით, რასაც ის მოგცემს: მუხლი მოიყვანე სიტყვასიტყვით და მიუთითე matsne.gov.ge-ის ოფიციალური ბმული.
```

როგორ უპასუხოს, ამას კონექტორი თავად ეუბნება ასისტენტს დაკავშირებისას; ეს ტექსტი მხოლოდ იმისთვისაა, რომ ასისტენტმა კონექტორი გამოიყენოს. ტექსტი კოდიდან იქმნება (`backend/app/services/connector_guidance.py`): შეცვალე კოდი და გაუშვი `python scripts/write_client_files.py`.
